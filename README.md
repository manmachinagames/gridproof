# Gridproof: Daily Logic Puzzles

Offline logic puzzles for Steam, part of the Proof series. Godot 4.7, GDScript.

Sudoku, Nonograms, Kakuro, Slitherlink, Hashi and Numberlink. Every puzzle has exactly one solution and can be solved by logic alone; hints explain the next deduction. Three dailies every day and a Learn mode for every technique.

Status: designed (`docs/design.md`), not built yet. Builds on `manmachinagames/proof_core` from day one.
